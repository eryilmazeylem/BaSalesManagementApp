# BaSalesManagementApp

BaSalesManagementApp, işletmelerin satış yönetimini kolaylaştıran, kullanıcı dostu bir uygulamadır. Satış yönetimi, CRM entegrasyonu, envanter takibi ve raporlama gibi temel özellikler sunar.

## 🚀 Kullanılan Teknolojiler
<ul>
   <li>ASP.NET Core MVC – Uygulama altyapısı ve MVC mimarisi</li>
   <li>Entity Framework Core – ORM ve Code First yaklaşımı</li>
   <li>SQL Server – Veritabanı yönetimi</li>
   <li>Identity Framework – Kullanıcı kimlik doğrulama ve yetkilendirme</li>
   <li>AutoMapper – Veri dönüşümleri</li>
   <li>JavaScript & jQuery – Dinamik işlemler</li>
   <li>Bootstrap – Responsive UI tasarımı</li>
</ul>

## 📂 Proje Yapısı

<ul>
   <li>Controllers – İş mantığı ve yönlendirme</li>
   <li>Models – Veritabanı yapıları ve işlemleri</li>
   <li>Views – Kullanıcı arayüzü</li>
   <li>Data – Veritabanı bağlantıları</li>
   <li>Services – Çekirdek iş mantığını içeren servisler</li>
</ul>
